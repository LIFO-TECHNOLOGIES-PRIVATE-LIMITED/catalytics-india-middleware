Data Mapping: Tally Catalytics

Fields fetched from Tally and synced to Catalytics backend

Customer Data

From Tally

  • NAME - Customer name
  • GSTIN - GST number
  • PAN - PAN card
  • ADDRESS - Full address
  • STATE - State name
  • PINCODE - Postal code
  • MOBILE - Phone number
  • EMAIL - Email address

SQLite Middleware

  • Normalized fields
  • Duplicate prevention
  • Sync status tracking
  • Error logging

To Catalytics

  • Full Tally ledger JSON
  • /import/tally-customer-payload/
  • Customer model created
  • PostgreSQL storage

Product Data

From Tally

  • NAME - Product name
  • HSNCODE - HSN code
  • BASEUNITS - Unit (kg, nos)
  • STANDARDPRICE - Rate/Price
  • PARENT - Category

SQLite Middleware

  • Normalized fields
  • Duplicate prevention
  • Sync status tracking
  • Error logging

To Catalytics

  • Full Tally stock item JSON
  • /import/tally-product-payload/
  • GasType model created
  • PostgreSQL storage

Invoice Data

From Tally

  • VOUCHERNUMBER - Invoice no
  • DATE - Invoice date
  • PARTYLEDGERNAME - Customer
  • INVENTORY - Line items
  • LEDGERENTRIES - Amounts
  • Total & Tax calculated

SQLite Middleware

  • Normalized fields
  • Items JSON serialized
  • Sync status tracking
  • Per-company storage

To Catalytics

  • Full Tally voucher JSON
  • /import/tally-invoice-payload/
  • DeliveryChallan + LineItems
  • PostgreSQL storage
