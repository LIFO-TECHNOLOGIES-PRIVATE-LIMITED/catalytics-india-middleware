Customer Data

From Tally

  • NAME - Customer name
  • GSTIN - GST number
  • PAN - PAN card
  • ADDRESS - Full address
  • STATE - State name
  • PINCODE - Postal code
  • MOBILE - Phone number
  • EMAIL - Email address
→

SQLite Middleware

  • Normalized fields
  • Duplicate prevention
  • Sync status tracking
  • Error logging
→

To Catalytics

  • Full Tally ledger JSON
  • /tally-customer-payload/
  • Customer model created
  • PostgreSQL storage

Product Data

From Tally

  • NAME - Stock item name
  • HSNCODE - HSN code
  • BASEUNITS - Unit (CUM, kg)
  • STDCOST - Rate/Price
  • GSTRATE - GST %
→

SQLite Middleware

  • Name parsing (type code)
  • Canonical name dedup
  • Sync status tracking
  • Error logging
→

To Catalytics

  • Parsed product fields
  • /tally-product_name-payload/
  • Product model created
  • PostgreSQL storage

Invoice / DC Data

  • VOUCHERNUMBER - DC no
  • DATE - Voucher date

  • INVENTORY - Line items
  • LEDGERENTRIES - Amounts
→

SQLite Middleware

  • Normalized fields
  • Items JSON serialized
  • Sync status tracking
  • Per-company storage
→

To Catalytics

  • Full Tally voucher JSON
  • /tally-dc-name-payload/
  • DeliveryChallan created
  • PostgreSQL storage
